сравнение версий:

git diff показывает разницу между конкретными состояниями файлов. 

git show выводит информацию об одном конкретном коммите (кто, когда и какие именно строки поменял). 

git log просто выводит список истории. 
команда 

git log -S ищет по истории коммиты, в которых добавлялась или удалялась конкретная строка (например, def). 

команда git blame показывает, кто и в каком коммите написал каждую отдельную строчку в файле.
