рабочая папка — это обычная папка на компе, где лежат файлы с которыми мы сейчас работаем

индекс — промежуточная зона, куда мы кидаем файлы перед тем как их зафиксировать

коммит — сохраненная версия проекта, как чекпоинт

git — это локальная система контроля версий на компьютере. 

github — облачный сервис для хостинга репозиториев и совместной работы.

git diff сравнивает текущее состояние файлов в рабочей папке с индексом.

git diff --staged сравнивает файлы, уже подготовленные в индексе, с последним сохраненным коммитом.

использованные команды:

git status — показывает текущее состояние репозитория, измененные и новые файлы.

git diff — показывает построчные изменения до их добавления в индекс.

git diff --staged — показывает изменения, которые находятся в индексе и готовы к коммиту.
